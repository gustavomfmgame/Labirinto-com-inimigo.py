# Labirinto-com-inimigo

Projeto desenvolvido para praticar estruturas de dados e algoritmos.

## Recursos

- movimentação com WASD
- colisão com paredes
- inimigo que encontra o menor caminho usando Breadth First Search (BFS)
- reconstrução do caminho através de dicionário de predecessores

## Tecnologias

- Python
- collections.deque
- set
- dicionários
